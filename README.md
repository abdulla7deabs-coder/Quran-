# القرآن الكريم (PWA)

تطبيق ويب يعمل على الموبايل ويتثبّت على الشاشة الرئيسية. مستوحى من فكرة تطبيق Al-Quran (Free) دون نسخ كوده أو شعاره.

**المزايا:** قائمة السور وبحث، قراءة بالرسم العثماني، ترجمة إنجليزية اختيارية، تكبير الخط، علامات مرجعية بالضغط على الآية، متابعة القراءة، صوت مشاري العفاسي، وضع داكن، وعمل بدون إنترنت للسور التي فتحتها.

**المصادر:** النص والترجمة من [AlQuran Cloud API](https://alquran.cloud/api)، والصوت من cdn.islamic.network.

## النشر على GitHub Pages
1. ارفع الملفات على مستودع جديد.
2. Settings ← Pages ← Branch: `main` / root.
3. افتح الرابط من الموبايل واختر "إضافة إلى الشاشة الرئيسية".

للتجربة محلياً: `python3 -m http.server` ثم افتح `localhost:8000`.
